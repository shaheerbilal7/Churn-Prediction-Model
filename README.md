# Churn-Prediction-Model

Customer retention is vital for business growth. For this project, I built a predictive classification model to identify at-risk customers before they churn.

📊 Project Breakdown:

Performed exploratory data analysis (EDA) to highlight churn indicators.

Preprocessed customer demographic and usage features.

Trained and evaluated classification algorithms (Random Forest, Logistic Regression, Decision Trees) using ROC-AUC and F1-score.

Analyzed feature importance using SHAP values for model transparency.

🛠️ Tech Stack: 

Python, Pandas, Scikit-learn, SHAP, Matplotlib, Jupyter Notebook
